# Agent Guide

This repo is a local MBSE lab for OpenMBEE Flexo MMS, Eclipse SysON, and the
bridge workflow between them. Read `README.md` first for user-facing operations;
this file is the shorter maintainer guide for future agents.

## What This Repo Does

- Runs OpenMBEE Flexo MMS with the optional Flexo SysML v2 REST service.
- Runs Eclipse SysON as a graphical SysML v2 editor.
- Provides `scripts/flexo_syson_bridge.py` to export from Flexo, render a
  conservative SysML v2 textual snapshot, and import it into SysON.

Primary workflow:

```text
Flexo SysML v2 REST JSON -> SysML v2 textual .sysml -> SysON GraphQL import
```

Treat Flexo as the API-driven repository path and SysON as the graphical
review/editing path. Direct live repository sync is not implemented.

## Credential Rules

Do not commit runtime credential files:

```text
deploy/flexo-mms/.env
deploy/flexo-mms/env/*.env
deploy/syson/.env
```

Commit only the `.example` templates:

```text
deploy/flexo-mms/.env.example
deploy/flexo-mms/env/*.env.example
deploy/syson/.env.example
```

Flexo runtime secrets are generated by:

```bash
python3 scripts/flexo_mms_env.py init --with-sysmlv2
```

Rotate local Flexo credentials with:

```bash
python3 scripts/flexo_mms_env.py rotate-secrets
```

After rotating, restart Flexo. If you are preparing a commit or publication,
run a secret scan:

```bash
git grep -n -E 'thisissomethingreallylon[g]|admi[n]test|adminpasswor[d]|passwor[d]1|passwor[d]2|eyJhb[G]ci|SYSON_POSTGRES_PASSWORD=passwor[d]|JWT_SECRET=thi[s]' HEAD || true
```

Expected result: no output.

## Runtime Data Rules

Do not commit service runtime data:

```text
deploy/flexo-mms/data/
deploy/flexo-mms/backups/*.nq
deploy/syson/data/postgres/
```

The tracked `deploy/flexo-mms/mount/cluster.trig` is the local startup dataset.
When Flexo graph state matters, run:

```bash
python3 scripts/flexo_mms_env.py backup
```

That writes a backup and refreshes `mount/cluster.trig` unless
`--no-update-init` is used.

## Start and Health Check

Start Flexo:

```bash
python3 scripts/flexo_mms_env.py up --wait --timeout 60
```

Start SysON:

```bash
docker compose -f deploy/syson/docker-compose.yml up -d
```

Check status:

```bash
make status
```

Collect a redacted diagnostics bundle after service failures:

```bash
make diagnostics
```

The bundle is written to `diagnostics/latest/` and is ignored by git.

`flexo-to-syson` writes structured run logs under `runs/flexo-to-syson/` by
default. That directory is ignored by git. Use `--run-log <path>` when a task
needs a stable log file name.

Equivalent explicit commands:

```bash
python3 scripts/flexo_mms_env.py status --with-sysmlv2 --strict
docker compose -f deploy/syson/docker-compose.yml ps
curl -s http://localhost:18083/projects | jq
curl -I http://localhost:18090/
```

If Flexo SysML v2 project creation fails because the `sysmlv2` org is missing:

```bash
python3 scripts/flexo_syson_bridge.py init-flexo-org
python3 scripts/flexo_mms_env.py backup
```

## Bridge Workflows

List Flexo projects:

```bash
python3 scripts/flexo_syson_bridge.py flexo-list-projects
```

Create a Flexo project:

```bash
python3 scripts/flexo_syson_bridge.py flexo-create-project "Example Model"
```

Export Flexo JSON:

```bash
python3 scripts/flexo_syson_bridge.py flexo-export <flexo-project-id>
```

Render `.sysml`:

```bash
python3 scripts/flexo_syson_bridge.py render-sysml exports/flexo/<flexo-project-id>.json
```

Inspect the fixture-derived deployment runtime contract:

```bash
python3 scripts/flexo_syson_bridge.py deployment-contract
```

Verify the running Docker containers against that contract:

```bash
python3 scripts/flexo_syson_bridge.py deployment-verify
```

Create a SysON project:

```bash
python3 scripts/flexo_syson_bridge.py syson-create-project "Imported From Flexo"
```

Find a SysON namespace/root package:

```bash
python3 scripts/flexo_syson_bridge.py syson-roots <syson-project-id>
```

Full bridge:

```bash
python3 scripts/flexo_syson_bridge.py flexo-to-syson <flexo-project-id> \
  --syson-project-id <syson-project-id> \
  --namespace-id <syson-root-package-id>
```

## Verification Before Commit

Run:

```bash
make check
```

Equivalent explicit commands:

```bash
python3 -m py_compile scripts/flexo_mms_env.py scripts/flexo_syson_bridge.py
docker compose -f deploy/flexo-mms/docker-compose.yml config --quiet
docker compose -f deploy/syson/docker-compose.yml config --quiet
git status --short
```

If you changed credential handling, also run the secret scan from the credential
section.

Run the optional live service evals only when Flexo and SysON are running:

```bash
make live-eval
```

They create and delete disposable Flexo/SysON projects.

## Known Limitations

- The bridge currently renders only a subset of SysML v2 element types.
- Unsupported elements remain in the Flexo JSON export but are not emitted into
  the `.sysml` file.
- Diagram layout and SysON graphical views are not round-tripped.
- SysON and Flexo remain separate repositories; the bridge is a snapshot import
  path, not a live sync.
