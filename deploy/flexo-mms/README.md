# Flexo MMS Local Environment

Generated by `scripts/flexo_mms_env.py`.

## Commands

```bash
python3 scripts/flexo_mms_env.py up
python3 scripts/flexo_mms_env.py status
python3 scripts/flexo_mms_env.py token
python3 scripts/flexo_mms_env.py backup
python3 scripts/flexo_mms_env.py down
```

Local runtime env files are generated by `init` and ignored by git. Publishable
templates live beside them as `.example` files.

`backup` writes ignored N-Quads backup files by default. Updating the tracked
startup seed requires explicit intent:

```bash
python3 scripts/flexo_mms_env.py backup --update-init --i-understand-this-updates-tracked-seed
```

Use that path only when the seed contains synthetic, publishable data.

The normal `docker-compose.yml` is the persistent local lab deployment. The
`docker-compose.isolated.yml` overlay is for disposable smoke tests; it omits
fixed container and network names, binds host ports to localhost, and expects
temporary data paths supplied by `mbse-lab deployment isolated-smoke`.

Rotate local credentials:

```bash
python3 scripts/flexo_mms_env.py rotate-secrets
python3 scripts/flexo_mms_env.py down
python3 scripts/flexo_mms_env.py up --wait --timeout 60
```

Core services:

- Layer1 API: http://localhost:18080
- Auth login: http://localhost:8082/login
- Fuseki: http://localhost:3030
- MinIO: http://localhost:9000
- SysML v2 API: http://localhost:18083
