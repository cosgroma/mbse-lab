# Execution Plans

Use this directory for work that is too large to rely on chat history alone.

```text
docs/plans/active/       Plans currently being executed
docs/plans/completed/    Completed plans with final decisions and validation
```

Each plan should include:

- objective
- relevant files
- planned steps
- progress log
- validation commands
- decisions and tradeoffs
- follow-up debt

Small changes do not need a checked-in plan. Large bridge changes, persistence
changes, credential handling changes, and live-service workflow changes should
use one.
